# Maharasa Portal

Project conventions, architecture rules, and Phase 1 / Phase 2 boundaries live
in [CLAUDE.md](CLAUDE.md). Read that file before making changes — it applies to
every agent working in this repo, not just Claude Code.

Quick reminders:

- Application data belongs in `src/data/applications.ts`, never in components.
- All reads go through `src/services/applicationService.ts`.
- Colors come from the oklch tokens in `src/styles.css` — never hardcode a hex.
- Routing is TanStack Start file-based (`src/routes/`); `routeTree.gen.ts` is
  generated by the router plugin.
- Do not implement SSO or the Admin Panel; the types only prepare for them.
